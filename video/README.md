# KT 옵티 튜토리얼 영상 녹화

Scene 1부터 8까지 손대지 않아도 사람이 쓰는 것처럼 자동으로 진행되는 화면입니다. 화면 녹화만 켜 두면 됩니다. n8n에는 연결하지 않고, 미리 받아 영상용으로 손본 응답(`fixtures/`)을 씁니다.

```bash
npm run video
```

브라우저를 1920×1080 전체 화면으로 두고 `http://localhost:4000/video/flow.html`을 엽니다. 3초 뒤 시작해 약 2분 30초 동안 진행됩니다. 녹화하는 동안 창을 맨 앞에 두세요. 가려진 창은 브라우저가 타이머를 늦춥니다. 화면에 커서를 직접 그리므로 녹화 프로그램의 커서 캡처는 끄세요(OBS: 커서 캡처 해제).

## URL 옵션

| 옵션 | 기본 | 뜻 |
|---|---|---|
| `lead` | 3 | 시작 전 대기 (초) |
| `speed` | 1 | 머무는 시간 배율. 내레이션에 맞춰 늘릴 때 (예: 1.5) |
| `type` | 1 | 손동작 배율: 타자, 커서 이동 (예: 0.8이면 빠르게) |
| `cursor` | 1 | 0이면 화면 커서를 그리지 않습니다 (편집기에서 커서를 얹을 때) |

클릭 위치와 시각(cue)은 끝날 때 콘솔에 나오고, Alt+C로 복사됩니다. 편집기에서 커서를 다시 얹거나 자막 타이밍을 잡을 때 씁니다.

## 장면

| 장면 | 화면 | 내용 |
|---|---|---|
| 1 | `flow.html` | 범용 AI에 U00864 고객의 요금제를 묻습니다. 이모지 가득한 답으로 "이미 완벽한 요금제"라며 유지를 권하고, 디즈니+를 안 쓰고 결합도 안 했다고 지적하자 크게 사과하면서 정보만 되묻습니다 |
| 2 | `flow.html` | 같은 창의 KT 옵티 탭으로 전환 |
| 3–7 | 실제 `index.html` + `driver.js` | 요청 고객 이현서 선택 → 검토(본인 월 −41,301원, 가족 −78,653원) → 초이스90 계산 근거 → 가정 바꿔 보기(선택약정, 결합 할인 최대) → 디즈니+·넷플릭스 질문 → 사용량·가족결합 탭 → 안내 문자 요청 |
| 8 | `scene8-send.html` | CRM에 초안을 붙여 넣고, 고객명 변수를 넣고, 선택약정 문장을 지운 뒤 발송. 휴대폰 미리보기가 바뀐 곳을 표시합니다 |

장면만 따로 볼 때: `http://localhost:4000/?play=1` (Scene 3–7), `http://localhost:4000/video/scene8-send.html?play=1` (Scene 8)

## 파일

- `flow.html`: 전체 흐름. Scene 1–2와 장면 전환
- `driver.js`: 실제 제품 화면을 진행합니다. 날짜 고정(2026-10-12), 고정 응답, 녹화용 화면 정리(제품 이름 KT 옵티, 결론을 미리 보여 주는 카드 설명·내부 안내 문구 숨김, 한글 라벨 글꼴), 전환 효과. `index.html`은 바꾸지 않습니다
- `human.js`: 한글 자모 조합 입력(ㄱ → 고 → 곡 → 고개 → 고객), 화면 커서, 대기·손동작 속도 분리
- `scene8-send.html`: CRM 발송 화면. 이름 마스킹, byte 표시, 휴대폰 미리보기([Web발신]), 발송 확인 창
- `serve.js`: 녹화용 서버. `index.html`에 `human.js`와 `driver.js`만 끼워 넣습니다
- `fixtures/`: 고정 응답. 무엇을 손봤는지는 `fixtures/README.md`
