# 녹화용 고정 응답 (U00864 이현서)

영상 녹화가 매번 같은 결과로 나오도록 n8n 응답을 미리 받아 두고, 영상에 맞게 손본 파일입니다. 녹화 때 `driver.js`가 `/api/chat` 호출을 이 파일로 대신 응답합니다. **영상과 제품은 별개**라, 이 폴더의 응답은 n8n의 실제 응답과 다를 수 있습니다. n8n에서 받은 그대로의 검토 보고서는 `original/`에 있습니다.

- 받은 날: 2026-10-12, JSON Webhook (`server.js`의 기본 `CHAT_URL`). 분석 ID `A-2321`
- 화면 버전: `index.html` @ `9e7bb5e`
- 분석 기간: 2026-04-12 ~ 2026-10-12 (6개월 프리셋). 완전한 달은 2026-04 ~ 09이고, 10월은 진행 중이라 분석에서 뺐습니다

## 왜 이 고객인가

처음에는 U00603(김수서)을 썼지만, 결론이 "현재 유지"라 범용 AI의 답과 차이가 잘 보이지 않았습니다. U00864는 차이가 분명합니다.

| | 범용 AI (Scene 1) | KT 옵티 |
|---|---|---|
| 추천 | 지금 요금제(초이스 더블) 유지 | 초이스90 [넷플릭스] + 프리미엄 가족결합 |
| 본인 월 청구 | 154,000원 그대로 | 112,699원 (−41,301원) |
| 가족 전체 | 언급 없음 | 월 −78,653원 |
| 근거 | "디즈니+ 혜택으로 다양한 콘텐츠를!" | 디즈니+ 6개월 사용 0GB, 넷플릭스 월 20.66GB를 따로 결제, KT 인터넷 미결합 |

| 파일 | 영상에서 쓰는 곳 |

## 영상용으로 손본 것

- **보고서 (n8n 원본 기반):** 화면에 보이는 영문 서비스명만 한글로 바꿨습니다(Netflix → 넷플릭스, Disney+ → 디즈니+, YouTube → 유튜브). 월평균 163.24GB는 163.2GB로 맞췄습니다(왼쪽 고객 정보와 같은 값). 금액·순위·계산은 그대로라 화면의 `selfCheck`를 통과합니다
- **후속 답변 (직접 작성):** 월별 값은 보고서 `services[디즈니+·넷플릭스].monthly_gb`, 넷플릭스 정가 13,500원 그대로입니다
- **문자 초안 (직접 작성):** 금액은 보고서 `decision`과 선택지 값입니다 (본인 −41,301원, 가족 −78,653원, 선택약정 시 초이스90 90,199원). 선택약정 문장은 일부러 넣었습니다. 고객이 받을 수 있는지 모르는 할인이라 Scene 8에서 마케터가 지웁니다
